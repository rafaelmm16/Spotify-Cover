# 🎵 Spotify Web Player – Aplicação Next.js

Este diretório contém o código-fonte da aplicação Spotify Web Player construída com **Next.js 16**, **Tailwind CSS v4** e **TypeScript**.

Para a documentação completa do projeto, consulte o [README.md principal](../README.md).

### Scripts Disponíveis

```bash
# Iniciar ambiente de desenvolvimento
npm run dev

# Gerar build estática para produção
npm run build

# Executar linting de código
npm run lint
```
